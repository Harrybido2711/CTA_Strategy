# Skills Index

A dict-like lookup for this repo's reusable skills — **read this file first**,
find the skill by name, then open the file. Each skill is self-contained and
lives in this folder.

| Skill | What it does | File | Use it when |
| --- | --- | --- | --- |
| `colors` | the figure colour system: semantic blue/green/violet, the tokens, usage rules | [`colors.md`](colors.md) | choosing or changing any figure's colours |
| `figures` | how to add, style and regenerate a chapter figure (tokens, light/dark, `<picture>`, dead-figure rule) | [`figures.md`](figures.md) | adding or revising any figure |

Every skill file has the same shape — YAML frontmatter (`name`, `description`),
then `## When to use`, `## The system`, `## Procedure`, `## Traps`.

To add a skill: write the file in this folder, then add one row to this index.
